# 01-FIRST-STREET-VISION

## 状态

C2 = `DESIGN / SPEC / SCAFFOLD PREPARATION`  
不是 UE gameplay implementation。

## 一句话

镜界服务器已经存在的 17 个真实逻辑地点，第一次拥有稳定的、可替换的、非 authoritative 的 3D 空间身体设计。

| 角色         | 职责                       |
| ------------ | -------------------------- |
| Server       | 决定居民在哪里、在做什么   |
| First Street | 决定“哪里”在人眼中长什么样 |
| World Truth  | 永远在服务器               |
| 3D           | 永远是 Presentation        |

## 视觉方向

近未来现实主义：

- 干净
- 克制
- 轻科技
- 可信的人类生活空间
- “第二人类世界”的第一条街

不是赛博朋克大都市，不是 MMORPG 主城，不是后台 Dashboard。

## C2 目标

1. 读取真实 17 Places
2. 定义视觉空间与 topology
3. 定义 Place / Resident visual binding
4. 决定 UE repo / LFS / module 策略
5. 规划 Greybox 与后续 C3

## C2 非目标

- 启动 UE Editor
- 创建正式 UE project
- 下载资产
- 接 realtime server
- 实现 Player Character
- 修改 schema / Kernel / M3 semantics
- merge main
