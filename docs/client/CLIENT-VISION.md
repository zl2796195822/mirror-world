# CLIENT-VISION

## 产品命题

镜界是 Persistent Digital Society。世界先存在，用户在某一时刻进入其中。

客户端关闭、崩溃、掉线、重装，都不会改变世界本身。客户端只是世界的窗口，不是世界本身。

## 三个角色

| 角色                         | 一句话               |
| ---------------------------- | -------------------- |
| World Server                 | 决定世界发生了什么。 |
| Mirror World Observer（Web） | 看懂世界。           |
| Mirror World Client（3D）    | 走进世界。           |

## Client V0 目标

第一阶段名称：`Mirror World Client V0 — First Street Observer & 3D Prototype`。

成功标准不是画面漂亮，而是：

1. 打开浏览器，第一次真正看见镜界“活着”。
2. 打开第一条街 3D，看见同一批真实居民逻辑状态被正确表现。
3. 客户端任何故障都不写回世界 Truth。

## V0 必须回答的观察问题

- 现在是什么 World Time？
- 这个世界有多少居民？
- 他们现在分别在哪里？
- 他们正在做什么？
- 刚刚发生了什么？
- 为什么某个居民做这件事？

## 明确非目标（V0）

- Player body / combat / quests / inventory UI / economy UI
- LLM dialogue / memory UI / relationship UI / voice / MetaHuman
- vehicles / large city / multiplayer / VR / AR / mobile 3D
- weather simulation / housing customization / marketplace / UGC
- God Mode（直接传送、改资源、改 Need、改 World Time）
- 把 Observer 登录账号自动等价成 Resident

未来模块若必须出现在 UI 中，只能是 `disabled` / `placeholder` / `future capability`，不得创建假后端能力。
