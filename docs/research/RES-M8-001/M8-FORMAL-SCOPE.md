Compressed candidate for **future formal M8**. Research recommendation only — not a roadmap edit.

## Explicitly OUT of Formal M8 v1

See also task §74:

- Multi-region active-active
- Global city sharding
- Kafka event mesh as truth
- Complex distributed actor system
- LLM-generated missing history
- Full M6 economy
- Full M4 society
- Real-world API dependency for continuity
- Timeline branching / rollback UX
- Global news system
- S1/S2 coarse fidelity as default

## Success Definition

Formal M8 v1 succeeds if:

1. Process restart does not lose world continuity
2. Scheduler queue loss is recoverable
3. Offline 7d/30d catch-up reaches target with real events
4. No LLM required
5. Digest shows committed history
6. Equivalence holds under deterministic assumptions
7. PAUSED does not catch up
8. World isolation preserved

## Naming

“Persistent World Foundation” may be a clearer milestone name than “Offline Simulation” to avoid implying a separate parallel simulator.
