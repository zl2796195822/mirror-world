# M4-GATE-PROPOSAL

只建议，不正式修改 roadmap。

## 1. Gate 候选检查项

1. 30 NATIVE residents 可形成 episodic memories
2. 多次互动可形成差异化 relationship states
3. relationship directionality 可验证（A→B ≠ B→A）
4. memory source lineage 可查询
5. **no global omniscience**（在家居民不自动记得咖啡店事件）
6. world isolation / resident isolation
7. deterministic zero-LLM baseline 同输入同结果
8. duplicate projection 不重复加减
9. forgetting 不修改 world_events
10. pgvector 可删除，structured truth 仍在
11. restart 后 memories/relationships 仍在
12. relationship re-derived projection 在 pinned policy 下稳定
13. SocialPressure 与 Relationship 无非法耦合
14. Decision Observation ≠ Perception Observation 契约未被合并

## 2. Society Alpha readiness（M4 PASS 后）

30 residents 至少应：

- 记得关键互动
- 对不同居民形成不同关系
- 行为可受过去影响（经 bounded read）
- 关系/记忆重启不消失
- Memory 不覆盖 World Truth
- Replay / lineage 可验证

## 3. 不作为 Gate 的内容

- 3D 视觉感知
- LLM 对话质量
- 机构/文化记忆
- 大规模性能 SLA（除非另有 benchmark）
