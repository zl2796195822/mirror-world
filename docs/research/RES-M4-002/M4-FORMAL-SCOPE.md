# M4-FORMAL-SCOPE

## 1. 建议最小正式范围（未来 M4）

1. **Perception Observation Contract**（与 Decision Observation 分离）
2. **Event → Observation Eligibility**（semantic location v1）
3. **Episodic Memory**（structured core + lineage）
4. **Minimal Semantic Consolidation**
5. **Directional Relationship State**
6. **Relationship Projection**（observed interactions only）
7. **Memory Retrieval Port**（resident-scoped）
8. **Forgetting/Retention baseline**（policy-versioned）
9. **Replay/lineage verification**（至少 re-derived deterministic + restart persistence）

## 2. 明确不做（M4 Deferred）

- LLM Agent / AI Conversation Runtime
- Institutional Memory
- Collective Memory / Culture
- Full emotional simulation
- Procedural learning
- Vector-provider lock-in
- Full social network productization
- Reputation economy
- Digital Twin personal memory import
- 3D raycast perception

## 3. 一句话

M4 的文明级意义是让居民第一次拥有：

> 过去、关系历史、主观经验、对他人的持续认识。

不是一次完成整个文明文化系统。
