# M4-TO-M6-CONTRACT

## 1. 分工

- **M4**：居民主观记忆与关系投影
- **M6**：Economy / Institutions / ledgers

## 2. 经济事件如何进入认知

未来：

```text
BUY / WORK / WAGE / RENT committed world events
→ perception eligibility
→ episodic memory / semantic belief
→ relationship projection (if socially interpreted)
```

例子：

- A 被 B 欠工资 → 可形成 memory；是否降低 A→B trust，由 relationship policy 决定
- Economy **不得** `trust -= 20`

## 3. 经济权威

- accounts/ledgers 属 M6
- M4 不拥有余额真相
- Resource snapshot 目前为 read bridge/fixture；正式经济权威后续迁移边界需另 ADR

## 4. 机构记忆

- 组织台账不在 M4 v1
- 若未来 institutional memory，也应与 personal memory 分权
