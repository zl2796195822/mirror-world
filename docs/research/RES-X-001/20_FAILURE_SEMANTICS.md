## Unresolved conflicts

1. M8 says offline continuity must be zero-LLM; M10 allows a cognition boundary during catch-up. The compatible interpretation is “apply an existing envelope or deterministic fallback, never create live LLM history”; the missing-envelope/provider-down branch remains `X-C016`.
2. Provider failure must not be treated as world failure. `STOP resident` is a poison/authorization/integrity isolation option, not the default for an unavailable provider; `STOP world` is integrity-fatal only.
3. Current PRE-AL-07 machine-readable failure items cover driver work, not full cognition/proxy/economy semantics. No current PASS claim extends beyond that scope.
