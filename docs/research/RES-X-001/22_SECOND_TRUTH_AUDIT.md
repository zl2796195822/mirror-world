## Non-negotiable boundary

Only Kernel-committed domain facts/events can change World Truth. Any derived source must expose source scope/cursor and be rebuildable or explicitly classified as evidence. The current PRE-AL-07 `scheduled_wake_registrations` is a rebuildable due projection, not a second Event Ledger.
