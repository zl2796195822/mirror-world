# Voice Boundary

Voice 是 embodiment/communication representation。voice model、voice clone、speaker embedding 或 TTS provider 不等于 Resident Identity、human proof 或 control authority。

未来 VoiceProfile 至少要引用：provider、artifact version、provenance、purpose、consentRef、revocation/status 和 retention policy；不要把 raw recording 或 derived biometric template 放进 Resident row 或 World Event。

语音生成“像某人”不能自动授权以该真人名义行动。公开发言仍需 separate action permission、risk/confirmation policy 与 audit attribution。M9 v1 不实现 voice cloning、speaker verification 或 audio capture。
