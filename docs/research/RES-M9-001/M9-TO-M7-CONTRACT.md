# M9 → M7 Contract

## M7 may receive

- `EmbodimentRef` / public visual profile;
- approved animation state and rebuildable world projection;
- explicit user interaction trigger, without hidden authority elevation。

## M7 must not receive

- Auth credential/session secret;
- Proxy Charter, spending budget or private identity proof;
- raw/derived biometric data unless a separate future capture flow grants a tightly scoped purpose;
- private memory/relationship data beyond a redacted presentation projection。

three-vrm/VRM is a replaceable renderer provider. MediaPipe is a capture/input provider. Neither is Identity Authority. Renderer, camera distance, visual LOD and asset hash cannot create or change ResidentId.

## Runtime rule

M7 cannot write location/activity/world facts, bypass ActionRequest/Kernel, or pause a resident/world because a tab or renderer is absent. It renders from durable truth and may change representation without changing identity。
