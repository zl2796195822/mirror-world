# Second Human World Identity Principle

## 宣言

镜界中的“人”不是账号、Avatar、LLM Agent、Prompt、Memory 文件或聊天 Session。它首先是具有持续 `ResidentIdentity`、世界历史和可追溯 origin 的存在。

- 真人通过 `AuthPrincipal → DigitalIdentity → ResidentLink` 进入世界；认证会话结束不删除居民。
- 原生数字居民从世界内部建立自己的 `ResidentIdentity`，不伪造 `ownerUserId=system` 来代替语义。
- Agent Runtime 是可替换的认知执行过程，不是居民本体。
- Proxy 是授权的控制/认知机制，不是居民本体，也不自动拥有真人全部权限。
- Avatar/voice/VRM 是 embodiment representation，不是身份 authority。
- Memory 和 relationship 是居民的认知/社会连续性状态，不是 ID 生成器。

## Authority split

```text
Authentication: 你是哪一个 AuthPrincipal？
Digital link:   这个人和哪个 DigitalIdentity 有什么映射？
Resident:       世界中哪个持续存在实体？
Authorization:  当前主体可以做什么？
Delegation:     谁允许谁代表谁做什么？
Kernel:         哪个 ActionRequest 可以成为事实？
```

这是研究决策，不是已写入 production code 的 policy。
