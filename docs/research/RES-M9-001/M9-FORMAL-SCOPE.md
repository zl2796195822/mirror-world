# M9 Formal Scope Proposal

## Minimum scope

Formal M9 v1 should establish only:

1. `DigitalIdentity` and world-scoped `ResidentIdentityLink`。
2. `ResidentOrigin` and creation/continuity lineage。
3. control grants and effective control arbitration。
4. `CognitionAuthority` metadata boundary。
5. Proxy Charter with least-authority capabilities。
6. machine-enforced delegation validation。
7. charter version, expiry and revocation fencing。
8. action world/control attribution。
9. separate identity/security audit history。
10. privacy/data classification and no-secret World Event invariant。
11. minimal embodiment/voice/capture/provenance ports。
12. compatibility contracts to M4/M5/M6/M7/M8。

## Explicitly out of scope

Government ID/KYC、legal contracts、inheritance、posthumous digital life、citizenship/voting/family law、AI legal personhood、identity marketplace、cross-world migration、multi-human collective resident、biometric matching engine、voice clone engine、face scan pipeline implementation、camera integration、full Proxy Runtime。

## Formal implementation prerequisite

This scope is not an authorization to start M9-T01. It is a candidate boundary that requires a fresh Compatibility Review against then-current main and formal ADR/task decomposition。
