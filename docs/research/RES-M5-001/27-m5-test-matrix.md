# 27 - M5 自动化验证测试矩阵 (M5 Test Matrix)

> **注**：本文件同时作为 `M5-TEST-MATRIX.md` 归档。

## 1. 验证目标与质量守卫原则

M5 Agent Runtime 是持久数字社会的认知执行引擎，其测试验证必须严格覆盖以下核心维度：

1. **权威隔离性**：证明 LLM 绝对无法直接修改世界事实；
2. **时序与并发安全**：证明版本栅栏、排他锁与并发限制在极端竞态下稳健生效；
3. **弹性容灾**：证明在提供商宕机、网络超时或队列背压时，世界主循环丝毫不受干扰；
4. **安全合规**：证明对抗性提示词注入无法突破系统特权防线；
5. **重放确定性**：证明历史事件重放完全独立于大模型，相同 Seed 下纯代码模拟完全自洽。

## 3. 测试通过验收标准（Gate Criteria）

当未来进入正式 M5 开发阶段时，上述 15 项集成测试必须**全部通过（15/15 PASS）**，且满足：

- 零 Flaky（非偶发性抖动）；
- 在 Mock 环境下单机运行全测试套件耗时 $< 30$ 秒；
- 形成完整的 `docs/verification/m5-report.md` 真实凭据。
