# EXP-3D-002 实验结果与技术观察 (Experiment Results)

---

## 1. 实验总体结论

本实验在 `EXP-3D-001` 技术骨架之上，全面引入了**中国南方写实城市街区资产（青禾街）**、**PBR 材质贴图**、**Day/Night/Rain 动态天气**、**官方 MIT VRM 人物模型**、**三级 Visual LOD**、**硬件 Instancing**、**Zone A/B/C 空间串流** 与 **KTX2/Draco 压缩管线**。

在桌面（1440×900）与移动模拟（390×844）环境下，系统维持了 **60~74 FPS** 的稳定帧率与 **423ms ~ 571ms** 的快速首屏响应。

实验判定结果为：**PASS_WITH_BOUNDARY（带边界通过）**。
- **通过项**：R3F + Three.js + Rapier + Ecctrl + 硬件 Instancing + Visual LOD + 空间串流链路具备承载写实青禾街区的基础可行性；
- **边界项**：未优化的原生高质量 VRM 模型（70万面/个）无法直接用于同屏 30 角色生产；移动端真实硬件（发热/显存/高DPR）仍需在 M7 制定严苛资产预算。

## 2. 场景写实度与细节还原（对照 A01 / C01~C04 母版）

1. **道路与标识系统**：
   - 18m 双向沥青主干道与交叉路，采用程序化合成的 512×512 PBR 漫反射与凹凸法线贴图；
   - 黄色实线双黄线、白色车道分界线、宽幅斑马线、人行道黄色凸起盲道与铸铁排水井盖全部还原。
2. **建筑与店铺立面**：
   - **青禾咖啡 (Corner Cafe)**：转角建筑外观，采用木纹条板外立面、暖色发光 "coffee" 艺术招牌、大面积落地透光玻璃与室外休闲木台；
   - **拾光便利店 (24H Store)**：便利店门头雨棚（橙白绿三色标）、店内明亮冷柜、商品陈列架与发光广告；
   - **办公大厦**：六层商务中心，采用高反射率蓝灰金属玻璃幕墙（metalness=0.85）；
   - **居民楼群**：4~5 层水泥抹灰外立面、多窗格、外挂空调室外机。
3. **市政基础设施**：
   - 青禾路公交站（雨棚、深色长椅、绿色 LED 公交到站预报屏）；
   - 沿街弯臂路灯与带树坑的行道绿化树木。

## 4. VRM 虚拟居民压力与 Visual LOD 收益

### 原始 VRM 的真实瓶颈
- 官方样例 `VRM1_Constraint_Twist_Sample.vrm` 单模型即包含约 **700,000 面片** 与 **280~310 次 Draw Calls**；
- 在无 LOD 保护下强行加载 30 个全量 VRM 时，场景总面片达 **340 万面**，Draw Calls 高达 **1062 次**，JS Heap 飙升至 **137.5 MB**。

### Visual LOD 介入收益
- 引入 **近景 25m LOD0（全量）/ 中景 45m LOD1（跳帧20FPS）/ 远景 LOD2（48面极简代理）** 后：
  - 远景 15~28 个居民转为 LOD2 极简代理，剥离全部骨骼蒙皮运算；
  - 帧率保持在 **70 FPS**（P95 仅 14.4ms），内存占用节约 **17.2 MB**；
  - 30 个虚拟居民沿着固定路径巡逻、斑马线漫步与公交站站立，且拥有固定相位差步态，完全可复现、无 `Math.random()`。

## 5. 硬件实例化收益 (Hardware Instancing)

- 对行道树（树干+树冠）、道路弯臂路灯、建筑外墙空调外机及路边石桩实施 `InstancedMesh` 批处理：
  - **开启 Instancing**：310 次 Draw Calls，77 个几何体；
  - **关闭 Instancing**：375 次 Draw Calls，136 个几何体；
  - **收益**：立减 **65 次 Draw Calls** 与 **59 个独立几何体**，避免了重复物体的驱动开销。

## 6. Ecctrl 复杂地形物理复核

在本次新增的复杂城市部件上深度复核 Ecctrl 控制器与 Rapier 物理交互：
1. **青禾咖啡 3 阶台阶 (Stairs)**：
   - 胶囊体控制器在 `shapeCast` 地面检测下能够平滑连续拾级而上，无明显卡顿或反弹。
2. **人行道 15° 斜坡 (Ramp)**：
   - 角色能够稳定沿 15° 斜坡行走与驻留，未发生滑坡或位移穿透。
3. **建筑间 1.8 米狭窄小巷 (Narrow Alley)**：
   - 两侧刚体碰撞体准确阻挡角色，转动镜头时未发生摄像机穿墙失控。
4. **关键缺陷发现与修复（物理穿透）**：
   - **现象**：当首屏加载大体积模型发生微小掉帧（瞬时 delta 较大）时，原本厚度仅 0.2m 的薄地面碰撞体曾导致角色发生**物理穿透（Tunneling）坠落**。
   - **修复与加固**：将地面物理碰撞体加厚至 **20 米地下刚体（Subterranean Foundation）**，彻底杜绝了帧率波动下的穿透缺陷。
